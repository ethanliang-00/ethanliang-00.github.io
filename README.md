# Zhicheng Liang — Personal Homepage

Personal academic website of Zhicheng Liang (梁志成).

Website: https://k-coconut.github.io/

## Files

- `index.html`, `styles.css`: current homepage.
- `assets/`: portrait, publication figures, and downloadable CV.
- `projects/web/`, `projects/posters/`: project videos and previews used by the homepage.
- `projects/`: original project media retained alongside the web versions.
- `cv/`: original CV and portrait.
- `archive/homepage-v2/`: previous homepage design and its assets.

## Preview locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/.

## Publish

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps the site buildless.
Push changes to `main` to update the website.
